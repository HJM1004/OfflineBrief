# GAS Web App デプロイ手順(初回のみ・所要5〜10分)

この手順は最初の1回だけ必要です。以降、Code.gs の中身を更新したときだけ「再デプロイ」を行えばOKです(手順5のみ繰り返す)。

このWeb Appは**読み取り専用**です(閲覧アプリからのデータ取得専用)。日々のニュースデータの書き込みは
Claudeが直接Google Driveに保存するため、このWeb App自体は秘密トークンなどの認証機構を持ちません。

## 1. 新しいApps Scriptプロジェクトを作る

1. ブラウザで https://script.google.com/ を開く(OfflineBriefのGoogleアカウントでログインした状態で)
2. 「新しいプロジェクト」をクリック
3. 左上のプロジェクト名を「OfflineBrief Backend」などわかりやすい名前に変更

## 2. コードを貼り付ける

1. エディタに最初から表示されている `Code.gs` の中身を全部消す
2. このリポジトリの `scripts/gas/Code.gs` の中身を全部コピーして貼り付ける
3. 左側の歯車アイコン(プロジェクトの設定)→「"appsscript.json" マニフェスト ファイルをエディタで表示する」にチェックを入れる
4. エディタに戻ると `appsscript.json` というファイルが増えているので、中身を `scripts/gas/appsscript.json` の内容に置き換える

## 3. 設定値を確認する

`Code.gs` の先頭にある `ROOT_FOLDER_ID` に、既存の「OfflineBrief」フォルダのIDが最初から入っています。フォルダを移動していなければそのままでOKです。念のため確認したい場合は、Google DriveでOfflineBriefフォルダを開き、URLの `folders/` の後ろの文字列と一致するか確認してください。

保存は Ctrl+S (Cmd+S) です。

## 4. ウェブアプリとしてデプロイする

1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 「種類の選択」の歯車アイコン→「ウェブアプリ」を選択
3. 説明: 任意(例: 初回デプロイ)
4. 「次のユーザーとして実行」: **自分**
5. 「アクセスできるユーザー」: **全員**
6. 「デプロイ」をクリック
7. 初回は権限承認画面が出ます。「アクセスを承認」→自分のGoogleアカウントを選択→「詳細」→「(プロジェクト名)に移動(安全ではないページ)」→「許可」と進んでください(自分だけが作ったスクリプトなので問題ありません)
8. デプロイが完了すると「ウェブアプリのURL」がこのダイアログの中に表示されます。`https://script.google.com/macros/s/......../exec` という形式のURLです。**このダイアログに表示された値をそのままコピーしてください**(下記の注意点を参照)。

**重要な注意点**: このURLをブラウザの新しいタブに貼り付けて開くと、ページを表示した後にブラウザのアドレスバーの表示が `https://script.googleusercontent.com/macros/echo?...` という別の(とても長い)URLに変わります。これは表示用にブラウザがリダイレクトされた後のURLであり、Claudeに伝えるべきURLではありません。**必ず、デプロイ完了ダイアログに表示された `https://script.google.com/macros/s/.../exec` 形式の方をコピーして使ってください**(動作確認のためにアドレスバーに貼り付けて開くのは問題ありませんが、コピーする元はダイアログの値にしてください)。

## 5. 動作確認

1. 手順4でコピーした `https://script.google.com/macros/s/.../exec` 形式のURLをブラウザの新しいタブで開いてください
2. `{"ok":true,"days":[]}` のようなJSONが表示されれば成功です(まだデータがないので days は空です)

## 6. Claudeに伝えること

デプロイ完了ダイアログに表示された、`https://script.google.com/macros/s/.../exec` 形式のウェブアプリのURLをClaudeに伝えてください。

## 今後コードを更新するとき

Claudeが `scripts/gas/Code.gs` を修正することがあります。その場合は以下の手順だけで反映できます(プロジェクト作成からやり直す必要はありません)。

1. script.google.com のプロジェクトを開く
2. `Code.gs` の中身を新しい内容に置き換えて保存
3. 「デプロイ」→「デプロイを管理」→ 既存デプロイの鉛筆(編集)アイコン→ バージョン「新バージョン」を選択→「デプロイ」
   - ※「新しいデプロイ」ではなく「デプロイを管理」から更新することで、ウェブアプリのURLは変わりません
